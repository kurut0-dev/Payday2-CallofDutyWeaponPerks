# Call of Duty Weapon Perks

Weapon perks from CoD: Mobile, offered in their own "Perk" slot in the modification menu. Every perk is available on every weapon. Akimbo is not ported because PAYDAY 2 has its own.

| Perk | Source | Classes | Effect |
|---|---|---|---|
| Sleight of Hand | CODM | all | Reload 25% faster |
| FMJ | CODM | all | Bullets penetrate enemy shields, +10% damage to armored enemies |
| Full Ammo | CODM | all | Larger ammo reserve |
| Disable | CODM | all | Leg shots stagger enemies (stands in for the movement slow) |
| Tough | CODM | all | +15% move speed for 10s after spawning |
| Long Shot | CODM | all | Better accuracy |
| Melee Master | CODM | all | Melee kills and kills within 3m return 3 bullets |
| Bullet Return | CODM | all | Kills have a 15% chance to refill the magazine |
| Fast Switch | CODM | all | Swap 40% faster |
| Empty Reload | CODM | all | Reload 30% faster from empty |
| Wild Hip Fire | CODM | all | Better accuracy while moving |
| Double Kill | CODM | all | Two kills within 2s refill the magazine |
| Fast Reload Kill | CODM | all | Damaging an enemy gives 30% faster reloads for 3s |
| Speed Up Kill | CODM | all | Damaging an enemy gives +15% move speed for 2s |
| Slide Flak Jacket | CODM | all | 15% less damage taken while crouched (no slide in PAYDAY 2) |

Not ported: Wounding (no enemy health regeneration to block), Headshot Slow, Stealth Kill, Headshot XP, Rapid Fire (effect unclear) and Akimbo.

## Icons

To replace the icons, put PNGs named after the perk id (for example `sleight_of_hand.png`) in `icons_src/` and run `tools/make_icons.ps1`.
