# Call of Duty Weapon Perks

Weapon perks from CoD: Mobile, offered in their own "Perk" slot in the modification menu. Sleight of Hand, FMJ and Full Ammo are available on every weapon; the rest follow the weapon classes CoD: Mobile offers them on (pistols count as SMGs, revolvers as snipers). Akimbo is not ported because PAYDAY 2 has its own.

| Perk | Source | Classes | Effect |
|---|---|---|---|
| Sleight of Hand | CODM | all | Reload 25% faster |
| FMJ | CODM | all | Bullets penetrate enemy shields, +10% damage to armored enemies |
| Full Ammo | CODM | all | Larger ammo reserve |
| Disable | CODM | AR | Leg shots stagger enemies (stands in for the movement slow) |
| Tough | CODM | AR | +15% move speed for 10s after spawning |
| Long Shot | CODM | AR | Better accuracy |
| Melee Master | CODM | AR | Melee kills and kills within 3m return 3 bullets |
| Bullet Return | CODM | Sniper, Revolver | Kills have a 15% chance to refill the magazine |
| Fast Switch | CODM | Sniper, Revolver | Swap 40% faster |
| Empty Reload | CODM | LMG | Reload 30% faster from empty |
| Wild Hip Fire | CODM | SMG, Pistol | Better accuracy while moving |
| Double Kill | CODM | SMG, Pistol | Two kills within 2s refill the magazine |
| Fast Reload Kill | CODM | SMG, Pistol | Damaging an enemy gives 30% faster reloads for 3s |
| Speed Up Kill | CODM | Shotgun | Damaging an enemy gives +15% move speed for 2s |
| Slide Flak Jacket | CODM | Shotgun | 15% less damage taken while crouched (no slide in PAYDAY 2) |

Not ported: Wounding (no enemy health regeneration to block), Headshot Slow, Stealth Kill, Headshot XP, Rapid Fire (effect unclear) and Akimbo.

## Icons

To replace the icons, put PNGs named after the perk id (for example `sleight_of_hand.png`) in `icons_src/` and run `tools/make_icons.ps1`.
